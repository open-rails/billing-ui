# @openrails/billing-ui (moved)

This repository is archived. `@openrails/billing-ui` now lives in
[open-rails/openrails](https://github.com/open-rails/openrails) under
[`sdk/billing-ui`](https://github.com/open-rails/openrails/tree/master/sdk/billing-ui),
with its full history. It is versioned with OpenRails: each release `vX.Y.Z`
attaches `openrails-billing-ui-X.Y.Z.tgz`.

```sh
pnpm add https://github.com/open-rails/openrails/releases/download/vX.Y.Z/openrails-billing-ui-X.Y.Z.tgz
```

Tarballs up to v0.9.0 remain attached to this repository's releases.
